# 数字地形分析结构化问题抽取规则

## 适用范围

本模板用于从自然语言问题、论文描述或项目需求中提取数字地形分析
（Digital Terrain Analysis，DTA）的建模信息。常见任务包括河网提取、
子流域划分、汇流分析、地形分区和地貌特征分析。

## 输出结构

```json
{
  "建模目标": {
    "研究区名称": null,
    "建模用途": [],
    "输入数据": [],
    "输出结果": []
  },
  "应用背景": {
    "地理特征参数": {
      "区域面积": {"value": null, "unit": "km²", "raw": null},
      "平均坡度": {"value": null, "unit": "°", "raw": null},
      "高程落差": {"value": null, "unit": "m", "raw": null},
      "地形起伏度": {"value": null, "unit": null, "raw": null},
      "坡度分布": null
    }
  }
}
```

## 字段抽取规则

### 研究区名称

提取研究区、研究区域、流域、子流域、行政区或试验区名称。
同义表达包括 `study area`、`catchment`、`watershed` 和 `basin`。
无法确认时返回 `null`。

### 建模用途

提取数字地形分析的目标，可包含多个值：

- 河网提取
- 子流域划分
- 汇流分析
- 地形分区
- 地貌分析
- 坡度分析
- drainage network extraction
- watershed delineation
- digital terrain analysis

### 输入数据

提取建模使用的输入数据，例如 DEM、数字高程模型、等高线、坡度栅格、
土地覆盖数据或水文数据。保留原始数据名称，不要把未出现的数据补入。

### 输出结果

提取预期输出，例如河网、子流域边界、汇流累积量、坡度分区、地形分区
或高程积分曲线。

### 地理特征参数

- 区域面积：规范单位为 `km²`。
- 平均坡度：规范单位为 `°`。
- 高程落差：最大高程减最小高程，规范单位为 `m`。
- 地形起伏度：保留原文定义和单位，不同研究中的计算定义不能混用。
- 坡度分布：保留分级、统计或累计频率分布的原始描述。

## 模板判别规则

以下情况优先归入 DTA：

- 目标是河网、沟道、流域或子流域；
- 目标是地形、坡度、汇流或地貌特征；
- 输入核心数据是 DEM，且任务不是土壤属性制图。

如果同时出现土壤属性和地形分析目标，保留两个目标，但应说明主任务
和辅助分析任务，不要丢弃任一任务。

## 通用约束

1. 只使用输入文本中能够找到证据的内容。
2. 缺失字段使用 `null`；多值字段使用数组。
3. 不根据 DEM 的出现自动推断具体分析任务。
4. 不将数字表面模型（Digital Surface Model）自动归类为 DTA。
5. 输出必须是合法 JSON，不添加解释性段落。
